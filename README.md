# HeroLife — Module 01/20: Project Core

این ZIP یک **Snapshot کامل و قابل اجرا** از پروژه در مرحله 01 است، نه فقط چند فایل پراکنده.

## هدف این ماژول
- ایجاد اسکلت حرفه‌ای Android Native
- Kotlin + Jetpack Compose
- RTL و فارسی از روز اول
- معماری چندماژوله
- تعریف مدل‌های پایه بازی: XP، طلا، الماس، اولویت و Lane
- آماده‌سازی پروژه برای 19 ماژول بعدی

## اجرای پروژه
1. محتوای ZIP را Extract کنید.
2. کل محتوا را در ریشه Repository قرار دهید.
3. پروژه را با Android Studio باز کنید.
4. Sync Gradle را انجام دهید.
5. روی دستگاه یا Emulator اجرا کنید.

## قرارداد 20 مرحله
هر ZIP بعدی نیز یک **پروژه کامل و قابل اجرا** خواهد بود.
ماژول جدید به‌صورت مستقل در ساختار پروژه اضافه می‌شود، اما Snapshot جدید تمام مراحل قبلی را هم حفظ می‌کند.
بنابراین بعد از هر مرحله، Repository باید قابل Build و Run باقی بماند.

## ماژول‌های حاضر
- `app` — پوسته اجرایی اپ
- `core:model` — مدل‌های دامنه مشترک

## اصول ثابت
- فارسی و RTL
- بدون Energy
- XP برای رشد
- طلا برای Hero و آیتم‌های Hero
- الماس برای پاداش‌های واقعی زندگی
- Task Priority برای موتور Battle


## ZIP Module Loader

بدون Extract کردن در `module-zips/` قرار دهید. Gradle آن‌ها را هنگام Sync/Build
