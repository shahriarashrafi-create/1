# HeroLife — ماژول 01/20

پایه مهندسی اپ اندروید «قهرمان زندگی» با Kotlin + Jetpack Compose و ساختار ماژولار.

## این بسته چه دارد؟
- پروژه Android Native
- RTL از ابتدا
- ماژول `app`
- `core:common`
- `core:model`
- `core:navigation`
- مدل اولیه XP / طلا / الماس / اولویت کار / Lane
- صفحه پایه فارسی برای Smoke Test
- نقشه معماری ۲۰ مرحله‌ای در `docs/ARCHITECTURE.md`

## اجرا
1. پوشه را در Android Studio باز کنید.
2. Gradle Sync را اجرا کنید.
3. روی Emulator یا دستگاه Android اجرا کنید.

> نکته: GitHub فایل ZIP را خودکار Extract نمی‌کند. برای داشتن سورس قابل Build باید محتوای ZIP در ریشه Repository قرار بگیرد.
